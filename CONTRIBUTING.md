# Contribuir a Forja

¡Gracias por ayudar a mejorar Forja!

1. Describe el modelo de teléfono, versión de Android y método de acceso usado al informar un problema.
2. No adjuntes volcados que contengan datos personales. Forja no necesita cuentas ni datos de usuario.
3. Para sensores térmicos, incluye el nombre que publica `/sys/class/thermal/thermal_zone*/type` y la unidad que devuelve `temp`, si puedes compartirlo.
4. Para FPS, indica si `dumpsys SurfaceFlinger --list` y `--latency` devuelven datos en tu dispositivo.
5. Mantén las lecturas en modo solo lectura y no envíes mediciones a terceros.

Los cambios se revisan mediante pull requests. El proyecto se creó con asistencia de IA; revisa los cambios y prueba en un dispositivo real antes de distribuir una compilación.
